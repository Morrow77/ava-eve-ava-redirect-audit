Redirect CSV audit v9

Offline review of planned redirect mappings. Requires Python 3.12 or later. Recorded execution covers the isolated Linux Python environment only.

Save redirects.csv as UTF-8 with these required headers:

source,target,status
/old,/new,301

Optionally save priority.csv with a url header and one local path per record.

Create a new report file:

python3 redirect_audit_v9.pyz redirects.csv --priority priority.csv --output findings.csv

Omit --priority priority.csv when no priority list is available. The output directory must already exist. Existing output paths are refused, including input paths. The program reads back the report bytes before printing a JSON receipt containing bytes and sha256 to stdout. Exit 0 indicates the operation completed; input, export and file errors return exit 2 with an Audit error message on stderr.

A failed write may leave a partial new file. Check the exit status and receipt before using a report; use a fresh filename for a retry. Crash durability and recovery from disk failure have not been tested.

Without --output, CSV bytes go to stdout. Run the built-in regression suite with:

python3 redirect_audit_v9.pyz --self-test

Output columns are kind, source and detail. Every nonempty output cell, including headers, has a literal apostrophe prefix. Preserve this when importing as text. A header-only report means no findings under these rules. Review findings before changing production redirects.

Paths must begin with a single slash, with no whitespace or backslashes. Full external URLs are rejected. Case, query strings and trailing slashes are preserved. Supported statuses: 301, 302, 303, 307, 308; temporary statuses are flagged. Checks cover planned chains, cycles, competing source definitions and missing priority mappings. The utility does not fetch websites or verify live status codes, content, indexing or server behavior. Missing mappings may be intentional.

Limits: 5,000 redirect rows and 5,000 priority rows; each input up to 2,000,000 UTF-8 bytes, 20 columns and 4,096 UTF-8 bytes per cell. Optional columns need a cell in every record, even when empty. Output is bounded to 20,001 records including header and 4,000,000 bytes. Carriage returns inside report cells are rejected.
